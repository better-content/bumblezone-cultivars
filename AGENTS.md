## Scope

This repository contains the Better Content-owned Forge mod **Bumblezone Cultivars**.

- Mod ID: `bumblezone_cultivars`
- Artifact: `bumblezone-cultivars-<version>.jar`
- Java 17, Minecraft 1.20.1, Forge 47.4.13

Run `./gradlew verifyFull`, then commit and push coherent changes. Do not commit build output or runtime worlds.
